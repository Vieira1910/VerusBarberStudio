# **💈 VERUS BARBEARIA — SITE INSTITUCIONAL**

Desenvolvimento de um site institucional para a **Verus Barbearia**, criado com o objetivo de apresentar a identidade da barbearia de forma moderna, profissional e visualmente atrativa.

O projeto foi desenvolvido utilizando **HTML5 e CSS3**, com foco na organização das informações, identidade visual e experiência do usuário.

---

## **🛠️ TECNOLOGIAS UTILIZADAS**

- **HTML5**
- **CSS3**

---

## **✂️ FUNCIONALIDADES**

- Apresentação da Verus Barbearia
- Seção de serviços
- Organização de informações da barbearia
- Identidade visual personalizada
- Layout estruturado com HTML semântico
- Estilização completa utilizando CSS
- Utilização e organização de imagens
- Interface visual moderna e profissional

---

## **🎯 OBJETIVOS DO PROJETO**

O projeto teve como principais objetivos:

- Praticar a estruturação de páginas com **HTML5**
- Desenvolver layouts utilizando **CSS3**
- Trabalhar com hierarquia e organização visual
- Criar uma identidade visual para um negócio
- Desenvolver uma presença digital para a barbearia
- Aplicar conceitos de **Desenvolvimento Front-End**

---

## **📚 APRENDIZADOS**

Durante o desenvolvimento do projeto, foram praticados conceitos importantes de Front-End:

- Estruturação semântica com **HTML5**
- Estilização com **CSS3**
- Organização de layouts
- Utilização de imagens e elementos visuais
- Hierarquia visual
- Composição de páginas
- Criação de interfaces para a Web

---

## **👨‍💻 DESENVOLVIMENTO**

Projeto desenvolvido como prática de **Desenvolvimento Front-End**, colocando em prática conhecimentos de **HTML5 e CSS3** na criação de um site institucional para a **Verus Barbearia**.
